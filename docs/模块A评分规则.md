# 模块 A 评分口径

当前口径：module-a-lenient-v3。

- 完成一次有效分析后，A1—A5全部给分，不以证据不足留空。
- 满足本课核心要求且无明确问题给5分；文字中写明任务、教具用途、操作与辅助即是直接的设计依据，不强求照片。具体轻微不足或基本实施可辨但说明稍简给4分。
- 核心设计关系仍然笼统、关键对应关系不清，或明确不足但仍可使用给3分；不是缺某些次要细节就给3分。
- 整项无关联依据、仅列名称口号或有需大幅调整的核心问题给2分。一般情况最低2分。
- 必须综合全文而非仅看准备清单。没有精确数量、照片、尺寸、收纳或消毒专段不自动扣分；未写不等于未做，仍不能宣称属性已核实。
- 按每课实际目标判断适用性，不要求所有课程同时覆盖全部能力领域。分组、轮换、示范与辅助都是可行性依据；教师反思中的成效只作教师陈述。
- evidence_level增加partial：基本实施可辨、说明稍简，计4分。vague与missing仅用于核心关系笼统或整项无依据，不能用于次要细节缺失。
- 0分只适用于有直接证据的极端不合理、严重背离目标或根本不能使用，必须给出具体理由；不因缺资料给0分。
- A4安全独立采用扣分制：未见具体危险给5分；未提供材质、尺寸或消毒说明不扣分。明确危险逐项列事实与扣分，从5分扣至最低1分；极端情况可0分。A4低于2分触发安全否决。
- 分数与证据核实程度分开。有限依据显示“有限依据初评”，缺失信息如实保留；安全5分不代表材质、尺寸或性能已经核实，不作安全认证。
- 主请求和格式修复共用一套提示规则。服务端校验并落实下限、安全扣分与0分条件。
- 修改意见与评分分开：低于5分必须针对实际不足或核心依据缺口提供可执行措施，缺失或只有“建议完善”等空泛占位时，按现有流程最多自动修复两次；仍不合格则本次结果不保存。5分可提供标明“可选优化”的建议，无建议时统一显示“暂无必要修改”。
- 历史记录缺少修改意见时，页面及Excel导出显示“原评估未提供修改意见，可重新评估获取。”；未分析项目仍显示待评估，不自动编造建议。
- 页面、记录和导出支持0分，尚未分析的空白仍是空白。历史结果不自动改写，需要重新运行模块A应用新规则。

验证覆盖缺证五项全评分、宽泛描述2—3分、无明确风险安全5分、明确风险扣分、安全否决、有理由0分、无理由0分回到2分，以及合法0分与未分析空值的区分。
