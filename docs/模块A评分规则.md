# 模块 A 评分口径

当前口径：module-a-lenient-v2。

- 完成一次有效分析后，A1—A5全部给分，不以证据不足留空。
- 满足要求且无明确问题给5分；明确轻微不足给4分。
- 有相关设计意图但表述宽泛，或不足但仍可使用给3分。
- 仅笼统提及、缺直接依据或需要较大调整给2分。一般情况最低2分。
- 0分只适用于有直接证据的极端不合理、严重背离目标或根本不能使用，必须给出具体理由；不因缺资料给0分。
- A4安全独立采用扣分制：未见具体危险给5分；未提供材质、尺寸或消毒说明不扣分。明确危险逐项列事实与扣分，从5分扣至最低1分；极端情况可0分。A4低于2分触发安全否决。
- 分数与证据核实程度分开。有限依据显示“有限依据初评”，缺失信息如实保留；安全5分不代表材质、尺寸或性能已经核实，不作安全认证。
- 主请求和格式修复共用一套提示规则。服务端校验并落实下限、安全扣分与0分条件。
- 页面、记录和导出支持0分，尚未分析的空白仍是空白。历史结果不自动改写，需要重新运行模块A应用新规则。

验证覆盖缺证五项全评分、宽泛描述2—3分、无明确风险安全5分、明确风险扣分、安全否决、有理由0分、无理由0分回到2分，以及合法0分与未分析空值的区分。
