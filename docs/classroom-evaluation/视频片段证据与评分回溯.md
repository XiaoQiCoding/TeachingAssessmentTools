# 视频片段证据与评分回溯（试用版）

模块 B 新流程适用于不同课程，不把音乐、分类或生活技能任务写成固定课程规则。

1. 教案提取时，AI 自动生成观察任务、达成条件和允许辅助。页面按任务提供独立输入框，用户可修改参考条件，点击下一步即采用当前条件。AI 未说明的辅助条件明确标注为未明确，不编造量化门槛。旧记录的占位提示自动转换并请求 AI 补全；生成期间的用户修改不会被返回结果覆盖。
2. 第一轮默认提取音轨，用 MiniMax ASR 生成带时间文字稿，AI 按观察任务引用句子编号推荐区间并说明原因。程序从真实句子时间计算区间，前留5秒、后留15秒，超过60秒分段。可导入 SRT、VTT、带时间 JSON，并逐句修改时间和内容。文字稿只用于定位，不作为学生表现证据。全课均匀抽样（最多36张）改为补充检查；另提供3个与文字稿独立的基础检查区间。可在推荐区间内抽取6张画面，但图片始终是线索，不能证明连续完成或全课情绪稳定。
3. 在候选旁点击“连续片段分析”，或手工输入开始、结束秒数。单片段最多60秒，在浏览器中按实际时长录制为 WebM，保留源视频可用的声音。此过程需要视频正常播放，支持 Chrome 的 MediaRecorder/captureStream；不支持时可人工回看并补充证据。片段最多20MB，模型可能仍稀疏读取，不能保证逐帧观察。
4. 回看片段，核对任务、达成条件、实际学生反应、辅助、结果及迁移变化，勾选确认后采用。新的候选使用独立编号，不覆盖以前的已确认事件。
5. 新报告1.4使用 classroom-b-v5，仅采用明确确认并绑定本次视频的片段证据。理解、操作和迁移必须有任务及达成条件，且已确认正确或错误；迁移还必须说明原技能及变化情境。未核对、缺少字段或来源视频不一致的记录不参与评分。B5取消“没有情绪事件则自动满分”的兜底。

评分已改为0.5分梯度，4分为良好，普通达成不会直接得到满分。完成质量按已确认事实取均值（突出4.5、达成4、部分3、少量2、未达成1），量化到最近0.5分。质量明确未知时保留空分；优质标签没有具体事实时按普通达成处理。合理辅助不自动扣分，只有明确超过任务目标且有具体依据时才影响完成质量。4.5须至少3个不重叠机会、80%达成、一半有优质事实、覆盖全部预设对象，B3还需至少两个层级；5须至少5个不重叠机会、95%达成、90%优质事实，每名预设对象至少两次独立观察，关键证据前后位置跨度达到视频时长70%。时间跨度不等于连续观察覆盖率。这些是可审阅的试用锚点，不宣称已验证量表准确度，不按某个指定总分倒推。每项展示“本档依据”“上一档核验”、质量与覆盖统计、固定规则、证据和回放按钮；Excel和JSON保留相同依据。旧版报告保留历史标记，不自动改分。报告同时保存事件编号、时间范围、任务要求、实际反应、辅助、结果、复核时间和规则版本。

缺失指标保留空分。展示已取得证据的加权分及覆盖权重；五项均有有效证据时才生成模块总分及 A+B 总分。Excel 同样保留空分，不将待补证项作为0分生成总分。旧版报告保留为历史记录，可回看或手动重新生成，不自动覆盖。

主页面每条模块 B 证据可点击进入课堂页面回放。关闭页面后需要重新选择原视频；视频不长期保存。来源校验使用文件名、大小及修改时间组成的标识，能防止常见误选，但不是文件内容的密码学验证。旧记录未绑定来源的片段需要人工核对。

当前已增加独立音轨转写和基于文字稿的 AI 选段。MiniMax ASR `asr-1.0` 使用 `verbose_json` 和句子时间；原音轨每420秒切分，回填真实偏移。Node 服务流式接收最大1.5GB、4小时的视频，FFmpeg 提取音轨，后台任务进度可轮询和取消；处理结束删除临时文件，结果只在内存保留30分钟，文字稿和推荐片段随浏览器草稿保存。账号需有 ASR 权限；失败可导入字幕，不以模型猜测生成时间。Docker 需更新镜像以安装系统 FFmpeg，本地使用 ffmpeg-static；反向代理上传限制也必须容纳视频。尚未引入 Qwen/Gemini 或云端长期视频存储。声画识别仍需人工复核，未声称模型能逐帧观察。

本地检查：`npm run validate` 和 `npm test`。回归测试覆盖片段时间偏移、所有评分事件追溯、错误来源排除、未复核事件排除、迁移证据要求、缺证空分和固定规则重复计算一致性。真实视频及模型的理解准确性需要使用人工标注案例进一步验证。

## 接口与核验

- `POST /api/classroom/transcription`：视频原始请求体，`x-video-duration` 为视频时长；返回任务编号。此接口由 Node 服务处理。
- `GET /api/classroom/transcription/:id`：进度及完成后的文字稿；`DELETE` 取消任务。
- `POST /api/classroom/locate-transcript`：任务、文字稿和视频时长，返回有原句引用的推荐区间及未定位任务。
- 关键片段分析继续使用 `/api/classroom/video-candidates`，同时携带选段原因和文字稿引用。证据回溯保留这部分来源信息。
- 新测试覆盖字幕解析、虚构句子拒绝、真实 FFmpeg 音轨切分、ASR 420秒偏移、后台转写任务。使用合成语音验证过真实 MiniMax ASR 及文字稿选段链路；不代表真实课堂识别准确度已经验证。
- 接口依据：[MiniMax 官方 CLI 的语音转写说明](https://github.com/MiniMax-AI/cli/blob/main/skill/SKILL.md)、[官方语音识别调试页](https://solutions.minimaxi.com/debug/asr)。
