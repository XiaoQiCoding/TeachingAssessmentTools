# 模块 B 数值评分规则（2026-10-28）

生成报告时，B1—B5必须全部输出0—5的数值，不能返回空分或因为证据不足取消总分。B1—B4保留现有表现档位；没有可判断完成质量的有效记录，按0分初评，并说明这不等同于已观察到表现不合格。合理辅助不自动扣分。

B5使用无异常默认满分规则：当前采纳记录没有教具使用中的明确哭闹、尖叫、痛苦表情、持续回避等负向情绪行为时，给5分。存在负向行为则按实际记录评分。默认满分不补造情绪证据，也不表示已核实全课稳定。

各项权重12%，加权分为单项分÷5×12，模块B总分为五项加权分相加，范围0—60。显式0分保留，0总分同样正常显示和导出。未开始评估或重置后的空白记录不自动生成分数。

旧报告通过同一数值规范函数补齐缺失项并重算总分。总览、课堂报告、模块B单独Excel与A+B合并Excel使用相同规则。例如3.5、3.5、3.5、4、未记录B5，转换为3.5、3.5、3.5、4、5，总分46.8/60。
