# 课堂分析流程试用版（2026-10-20）

本轮评价范围仍是 B1—B5 的教具课堂应用表现，不将结果扩大解释为完整教学质量或教具的因果效果。

本文件记录完整检查基线。后续新增默认快速模式及服务器直接切片，当前流程以 [长视频快速分析](长视频快速分析.md) 和 [日志与耗时诊断](日志与耗时诊断.md) 为准。

## 分析顺序

1. 读取教案，提取目标、任务、达成条件、允许辅助，作为可编辑的观察参照。教案中的预期不作为已发生事实。
2. 按视频时长建立连续检查区间，单段最多60秒，相邻交界重叠5秒。依次检查画面和声音，不依赖字幕是否成功生成。
3. 每段分别寻找参与、理解、操作与分层、迁移、情绪行为事实，并保留活动摘要、未知与限制。模型完成分析的时段不等于逐帧观察或人工确认的范围。
4. 第一轮全部完成后，对于已有候选中无法判断或过程不完整的线索，调整时间窗口补查前后过程，最多6段，每轮评估只规划一次补查。没有任何可定位线索的指标，明确提示需要人工检查，不猜测时间、不凭空生成证据。
5. 人工回放确认后，形成评分建议。已有正式证据不会被补查自动覆盖，重叠片段中的同一候选进行合并。

## 各指标的观察重点

| 指标 | 观察重点 |
| --- | --- |
| B1 参与 | 不同活动中的参与、持续表现与回避 |
| B2 理解 | 任务要求、学生反应及所需辅助 |
| B3 操作与分层 | 不同观察对象在各自目标下的操作及辅助 |
| B4 泛化 | 明确发生材料或情境变化后的表现，重复原任务不计泛化 |
| B5 情绪 | 可见表情、哭闹、尖叫或回避等事实，不以无记录推断全课稳定 |

## 分数与证据范围

规则版本为 classroom-b-v6。仅按已核实表现的质量形成0.5分梯度评分建议：突出5、达成4、部分完成3、少量完成2、未达成1。突出须有具体事实支持，合理辅助不自动扣分。此规则仍为试用锚点，需要用人工标注课堂样本校准。

观察机会少、观察对象不全、跨层级证据不足等情况单独披露，不再通过统一的3次/5次或首尾跨度70%门槛降低表现分数。所有有证据的项目也只形成已复核片段的评分建议；单项缺证保留空分，存在缺项时不生成模块总分。

## 运行与兼容

- 主分析不再请求文字稿定位接口；字幕生成、导入及定位保留为选用工具。
- 429、529等可重试服务错误暂停后续片段请求，已完成进度保存，点击继续重试未完成部分。
- 已有记录和报告保留；旧版评分在查看时提示重新生成，不自动改写原分数。
- 当前连续视频片段仍由浏览器按播放速度准备，因此整段分析可能较慢；本轮未替换视频切片实现。
- 自动化与模拟接口测试只能验证流程和证据约束，不能替代真实课堂样本的模型效果评估。
