# 长视频快速分析（2026-10-20）

新建评估默认使用快速分析，可在上传材料时切换完整检查。旧的有片段记录默认恢复完整检查，保留原结果，不自动重跑。

## 快速模式

1. 原视频仍上传一次，复用临时源文件。快速初筛前自动提取音轨，调用现有 MiniMax ASR 生成带句子时间的文字稿；已生成或导入的同一视频文字稿直接复用。转写失败时保留进度并提示重试或导入字幕，不将失败误报为视频无声。未检测到音轨时仅分析画面。
2. 全课按120秒分批，在服务器每4秒抽取一张不超过640×360的图片，每批最多30张。同时附上与该区间有重叠的文字稿，提供原视频绝对秒数及本段相对秒数（例如第2批是120—240秒），仅发送对应语句；跨边界句保留全文和原时间，不估算逐字时间。初筛请求仅要求活动摘要、限制及最多2个需要连续检查的区间，不生成证据候选，不评分。
3. 初筛成功覆盖全课后，按任务、观察类别、观察对象和可见辅助选择代表性的20—60秒区间。同任务、同类别、同对象与相同辅助的常规重复推荐只选代表片段；可见困难、回避、异常和材料/任务/表现变化优先保留。额外加入首、中、尾最多30秒的固定抽查，避免只选成功表现；高度重叠区间去重。初筛提示词不要求每批凑满推荐数，任务等标签仅用于选段，不作为评分事实。
4. 精看使用现有视频分析及证据结构。千问可选每秒1帧或2帧，默认1帧；MiniMax保留其原视频接口，界面密度参数仅对千问生效。
5. 精看过程中，同一明确观察对象、同任务及辅助下，已有连续视频候选提供了过程完整、质量已知、对应观察类别的事实时，常规重复片段停止检查；变化、异常及独立抽查仍保留。候选不因此自动变成人工核实证据。自动补查只处理明确的过程不完整、截断或片段外问题，同任务、同对象与同类表现只补查一次，仍沿用最多6段的防护上限；纯未知、缺声音、遮挡或身份不明不自动反复补查。完整模式保留原补查策略。没有线索或缺证指标保留待评，不推测不存在的事件。
6. 可一键采纳连续视频AI候选生成评分建议，也可人工回放、修改并确认；两种采纳方式分开标注，缺证仍保留待评。

页面显示选段依据、未精看的重复线索及原因；这些范围不计入精看覆盖。新策略不按固定分钟截断，也不承诺固定减少比例。重复活动多时预计减少较多；任务、对象、辅助变化或异常较多时会保留更多片段。旧记录续跑保留已完成结果与历史耗时，旧版待执行推荐重新筛选；新开记录能完整使用新的初筛标签。

每阶段已完成结果保存到当前记录。暂停、过载、源文件过期时保留成功结果，继续只处理未完成区间；刷新后需要重新选择原文件并上传，原有结果保留。两种模式切换保留成功片段，完整检查会补建覆盖全课的区间。改变画面密度和模型仅影响后续请求。

## 观察范围及统计

界面分别显示初筛覆盖、连续片段分析覆盖、人工复核范围，时间段取并集，不重复累计重叠。初筛覆盖不意味着逐帧观察或全课不存在异常。

时间轴分别标注初筛、重点精看、全课检查及补查，并提供对应请求诊断。初筛与精看累计耗时、服务商实际返回的输入/输出token及有用量记录的请求次数，包括已记录的失败尝试。教案、转写、没有返回用量或旧版未记录的请求不计入该用量统计，不能据此推算完整账单或固定节省比例。

不使用加速播放的视频替代真实时间轴；原视频和证据绝对时间不变。文字稿可辅助识别口头指令与对话线索，但可能误识别或无法分清教师和学生，不能单独证明目标达成。低频图片不用于证明理解、连续完成、情绪稳定、口头指令或节奏正确。千问当前链路仍仅认定画面证据。低分辨率初筛可能漏掉小幅动作或表情，可补充指定区间、使用完整检查和人工回放。

## 验证

从webapp运行 `npm run validate` 与 `npm test`。新增快速模式测试覆盖初筛边界、绝对时间换算、无评分候选、用量回传、过载暂停、源过期、断点恢复与完整模式兼容。服务器测试使用FFmpeg实际抽帧，检查定位、帧数及临时清理。

可用 `node tests/video-source-test.mjs --real-case` 读取本地《小青蛙找家》原视频，仅验证抽帧和切片，不调用模型。此次本机120秒初筛抽取30张图片，合计885692字节，耗时794毫秒；此数据不代表服务器性能或模型处理耗时。

浏览器模拟验证使用合成视频与模拟模型响应，确认初筛与候选分离、范围展示及用量累计；不能证明真实课堂识别准确性或实际节省比例。真实效果需用同一课堂对照人工标注，比较关键事件漏检、有效证据、总用量和总耗时后再验收。

## 初筛失败后的继续入口

部分初筛成功时，可选择“使用已完成初筛，继续精看”，直接处理成功初筛推荐及固定抽查区间，不重跑失败初筛；失败和未完成范围仍保留，流程状态记为部分完成。已有候选可通过“下一步：核对已有片段”复核，至少确认一条正式证据后可生成缺证留空的报告。初筛图片和活动摘要仍不能直接评分。

刷新后恢复分析进度，需要重新选择同一个原视频。选择后可通过“返回分析进度”继续，不必重新上传教案或清空成功结果。

初筛推荐的短区间仅扩展检查上下文，长区间拆成不超过60秒的片段，越界部分裁去；完全无效的推荐舍弃，其他合法推荐保留，并记录处理原因。所有推荐均无效时仍报错，不编造时间。服务器读取实际生成的抽帧文件，避免视频末尾不足预估帧数时读取不存在的图片。真实原视频末段实测生成28张而理论上限为29张，已验证可正常读取；该验证不调用模型。

## 批量采纳与抽查

“一键通过并生成报告”会采纳未忽略、来源和时间有效的连续视频AI候选，直接用固定规则生成评分建议，不再调用模型。保留正向、负向和未知表现，不覆盖已有人为确认或修改的事件；稀疏图片线索不直接进入批量评分。未知质量、缺失任务字段或迁移情境的记录仍受原有证据校验约束，不能自动补成达标。

批量记录使用独立的AI采纳标记，不设置人工回看标记。页面、报告及Excel注明未逐条回看的范围，人工复核时长只统计实际回看确认的事件。“撤销上次批量通过”仅移除该批仍属于AI采纳的事件，保留原候选、人工修改及后来回看确认的记录。逐条回看与勾选仍可作为抽查路径使用。完整备份保留两种采纳方式及撤销记录。

## 2026-10-28 代表片段选段验证

`tests/focus-selection-test.mjs` 使用30条同任务、同对象、同辅助的重复推荐，旧策略33次精看，新策略4次、计划素材120秒；这是构造案例，不代表真实课堂节省或准确度。测试同时验证不同对象、辅助、变化和异常仍保留，初筛/稀疏图片不能触发证据充分停止，未精看不计覆盖，无法通过补片解决的问题不盲目重试。真实课堂准确度及漏检率仍需同课人工对照。

## 2026-10-28 临时故障自动恢复

初筛与精看共用自动恢复队列。遇到视频编号失效（410），清除旧编号，自动重新上传缓存的原文件并重试当前片段；网络故障、超时及临时服务错误自动等待2秒、8秒重试，单片段每轮最多3次应用请求（模型接口内部可能另有有限重试）。不重跑已成功片段，失败与成功尝试均记录耗时。等待时页面显示自动恢复进度，暂停可立即取消等待。

持续过载或网络故障在3次后保留进度并停止，避免反复请求整个剩余队列；认证/权限错误立即停下。单片段的不可恢复格式错误保留失败并继续其他片段，最终仍提示部分未完成。浏览器页面关闭后不会在后台继续执行，持续故障不能承诺自动完成。

测试包含暂时错误恢复后继续下一段、410后自动重新上传、等待中暂停、持续故障次数限制、权限错误停止，以及不重复成功结果和不漏计失败耗时。

## 2026-10-28 评分疑点核查 questions-v3

本节覆盖前面的代表片段策略：快速模式不再无条件加入首中尾抽查，也不因活动或辅助变化自动精看。完整检查仍保留逐段模式。

1. 全课初筛标记具体评分疑点、B1—B5指标、已见事实及核查手段。仅“会影响评分且连续画面可能解决”的不确定问题进入核查池。声音、身份、长期遮挡或没有迁移机会不靠重复无声片段解决。初筛图片仍不直接充当连续评分证据。
2. 按未解决的指标选择信息价值较高的区间，优先学生实际操作与反应，避免只看教师示范。一次核查可服务多个指标；未知身份不再强制反复检查课堂层面的可见事实，但明确不同学生不能互相替代。
3. 重叠区间合并，超过60秒拆成无重叠连续请求；已分析的时段从新请求中扣除。保留已有事实、人工确认和历史用量。缺失的连续上下文仍可造成无法判断，不能仅凭相邻片段摘要补成达标。
4. 每次请求前重新判断疑点是否已由连续视频候选回答。清楚的未达标同样属于已解决的判断，不为寻找成功反复看。未精看时段不计覆盖，候选仍需采纳或人工确认才进入报告。
5. 首轮仍未解决的指标，自动检查一个未分析的备选；仍不清楚保留待评，不无限追加。保留手工检查与完整模式。

针对本次实际记录的已保存初筛结果，本机重建首轮计划由31段变为2段；保留6段已完成结果续跑时，仅新增1段。这是计划回放，未重新运行全课模型，不能当作实际耗时、用量节省或准确度结论。测试覆盖旧记录续跑、重叠区间、已完成范围复用、明确负向事实、音频限制及自动补查终止。

## 2026-10-28 音轨文字稿初筛

快速模式现在先转写，再以对应两分钟的图片和带时间文字稿联合初筛。实际音轨交给 ASR，初筛模型收到图片和转写文字，未直接接收或核实原音频。无音轨、未识别出语句和未提供文字稿分别说明。暂停等待后继续可复用未完成转写任务；已完成文字稿保存到当前评估记录。历史已完成初筛结果不自动重跑；要比较新旧效果，应新建评估。转写仍使用 MiniMax 密钥及 ASR 权限，即使画面分析选用千问。
