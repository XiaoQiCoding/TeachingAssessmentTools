# 评估记录与页面导航

左侧导航固定显示总览、模块 A、模块 B。总览包含两个模块的结果表和合并导出；模块 A 只显示课前材料与 A 表；模块 B 保留独立的课堂工作页。切换页签仅隐藏或显示工作区，不销毁课堂工作页，不重新分析。

选择过的课前材料、教案、视频以 File 对象存入当前浏览器的 IndexedDB，按评估记录隔离。切换页签时保留原文件选择，整页刷新后恢复到文件输入框及本机播放器。文件保存未成功时显示原因提示，不把文件名当作已恢复文件。材料不通过该保存操作上传服务器，也不写入浏览器 localStorage。JSON备份包含评估和候选记录，不包含原视频等材料文件。

“重新开始评估”创建新记录，保留旧记录及其材料。通过“评估记录”列表可以切回旧评估。上传材料不会自动重跑 AI；只有明确启动分析才请求模型。恢复旧记录时也不自动补跑观察条件生成。

模块 B 的客观证据列只显示记录数量及“查看证据详情”。详情页集中呈现评分依据、范围、任务、实际反应、辅助、采纳方式以及视频回放，并可返回评分表或总览。Excel仍包含完整证据。

候选、正式事件、片段进度与报告同时写入正式评估记录；浏览器暂存过期时回退正式记录，空暂存不能遮住正式结果。父页面保存模块 A 时合并最新模块 B，避免两个工作区互相覆盖。

验证包括离线流程测试和独立浏览器试用：选择材料后往返 A/B，刷新恢复文件，重开评估不串材料，切回旧记录恢复，生成报告后从总览进入证据详情并返回。浏览器试用使用合成视频和模拟模型，不产生真实模型用量。
